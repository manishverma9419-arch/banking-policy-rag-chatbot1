Banking Policy RAG Chatbot

An AI-powered Banking Policy Chatbot built using Python and Retrieval-Augmented Generation (RAG). It helps users get answers to banking policy-related questions using relevant document context.

Features
Banking policy question answering
Retrieval-Augmented Generation (RAG)
Context-based responses
Document-based information retrieval
Python-based implementation
Tech Stack
Python
RAG (Retrieval-Augmented Generation)
Large Language Models (LLMs)
Vector Database / Embeddings (as implemented)

Installation
Clone the repository:
bash
git clone https://github.com/manishverma9419-arch/banking-policy-rag-chatbot1.git

Navigate to the project directory:
bash
cd banking-policy-rag-chatbot1

Create a virtual environment:
bash
python -m venv .venv

Activate the environment (Windows):
bash
.venv\Scripts\activate

Install dependencies:
bash
pip install -r requirements.txt

Run the Project

Run the application using the appropriate entry-point command for your project.
